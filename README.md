# Customer Churn Analysis Using R

## Business Problem
Understanding why customers churn and identifying high-risk segments.

## Dataset
Telco Customer Churn Dataset (Kaggle)

## Tools Used
- R
- dplyr
- ggplot2
- caret

## Key Insights
- Month-to-month contracts show highest churn
- Early tenure customers are most at risk

## Model
Logistic Regression
Accuracy: ~80%

## Business Recommendations
- Incentivize long-term contracts
- Improve first-year customer onboarding
